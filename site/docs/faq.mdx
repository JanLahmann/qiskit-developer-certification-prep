# Exam FAQ — C1000-179

Quick answers about the IBM Qiskit v2.X Developer exam. The exam facts below were checked against
[IBM's official exam page ↗](https://www.ibm.com/training/certification/ibm-certified-quantum-computation-using-qiskit-v2x-developer-associate-C9008400)
on **18 October 2026**. IBM can change them at any time, so check that page before you book.

:::info[Unofficial]
CertiQ is an independent community project, not affiliated with, endorsed by, or sponsored by IBM.
:::

## What is exam C1000-179?

**C1000-179 — *Fundamentals of Quantum Computing Using Qiskit v2.X Developer*** is the one exam
required for the credential **IBM Certified Quantum Computation using Qiskit v2.X Developer —
Associate** (credential code C9008400, which replaces the earlier credential C0010300). It tests
whether you can build and run quantum programs with the Qiskit SDK and Qiskit Runtime from Python.

## How many questions, how long, and what is the passing score?

| | |
|---|---|
| Questions | **68** |
| Questions needed to pass | **47** (about 69 %) |
| Time allowed | **90 minutes** |
| Language | English |
| Price shown for the United States | $200 USD (prices can differ by country) |

## What does the exam cover?

Eight sections, weighted as follows on the official page:

| # | Section | Weight | ≈ Questions of 68 |
|---|---|---|---|
| 1 | Perform quantum operations | 16 % | ~11 |
| 2 | Visualize quantum circuits, measurements, and states | 11 % | ~7 |
| 3 | Create quantum circuits | 18 % | ~12 |
| 4 | Run quantum circuits | 15 % | ~10 |
| 5 | Use the sampler primitive | 12 % | ~8 |
| 6 | Use the estimator primitive | 12 % | ~8 |
| 7 | Retrieve and analyze the results of quantum circuits | 10 % | ~7 |
| 8 | Operate with OpenQASM | 6 % | ~4 |

The question counts are our rounding of the weights, not official numbers. Each section has its
own [study page](/docs/sections/s1) here, with the official objectives and curated resources.

## What official preparation material does IBM offer?

The exam page links a **Sample Test**, a **Study Guide PDF**, an
**Assessment Exam** (an online practice test with a score report, booked through Pearson VUE) and
recommended courses. Take IBM's Sample Test once: it shows the question style better than any
description can.

## Which Qiskit version does it cover?

Qiskit SDK **v2.x** and **Qiskit Runtime**, including the Sampler and Estimator primitives.
Every CertiQ question is executed against a pinned stack (Qiskit 2.5.0, qiskit-ibm-runtime
0.48.0) with `SamplerV2` and `EstimatorV2`. Newer qiskit-ibm-runtime releases (0.50 and later)
deprecate those classes in favour of new executor-based primitives. The exam objectives still
name the sampler and estimator primitives, so CertiQ stays on the V2 primitives until the exam
changes.

## Is CertiQ official? Does it contain real exam questions?

No and no. CertiQ is unofficial. Its questions are written from the public exam objectives and
the open Qiskit documentation, never from exam content. Each answer is backed by an executed
proof or a cited documentation page.

## How close is the CertiQ mock exam to the real one?

The [mock exam](/mock-exam) uses the official format: 68 questions, 90 minutes and a pass line of
47. Its questions are sampled to match the official section weights and an easy/medium/hard mix,
and about a fifth of them use figures (circuit drawings, histograms, Bloch spheres). Your score
report shows which sections to revisit.
